# Decisions

One short record per decision that had a real alternative. Five sharp records beat twenty
thin ones.

## Format

Start from `docs/templates/decision.md`. Each record names the story that forced it, the
options, the decision, the numbers behind it, and the questions a reviewer will ask, answered
ahead of time.

## Status

- **Draft**: written, not yet owned. An agent may draft one when asked.
- **Accepted**: the human has rewritten it in their own words and stands behind it.
- **Superseded by NNNN**: replaced. Records are never edited after acceptance; a new record
  replaces an old one.
